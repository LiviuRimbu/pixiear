# PixieAR

Live project: [https://pixiear.com](https://pixiear.com)

PixieAR is a small web application that animates compatible book covers using Augmented Reality (AR).  
When a child points the camera at a book page, interactive 3D animations appear on top of the page.  
The app can also scan QR codes printed in the book to open related video lessons.

---

## Features

- Recognizes book covers and displays corresponding AR content.
- Scans QR codes to open video lessons.
- Works directly in the browser — PWA ready (requires only configuration; no offline content).
- Supports both mobile and desktop devices.

---

## Technology

- **Framework:** Next.js with TypeScript
- **Styling:** Tailwind CSS and Shadcn UI
- **AR Provider:** MyWebAR (iframe integration)
- **Hosting:** Netlify
- **Languages:** English, Romanian
